# .astro directory

This directory contains Astro CLI configuration and metadata.

## Contents

- `config.yaml` - Project configuration (name, organization)
- `dag_test_cache/` - Cached DAG test results (auto-generated)
- Other metadata files generated by Astro CLI

## Do Not Modify

Most files in this directory are auto-generated by Astro CLI.
Only modify `config.yaml` if you need to change project settings.

## Version Control

The `config.yaml` file should be committed to version control.
Other files (like cache) are typically excluded via `.gitignore`.
